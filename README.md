# 過去問演習アプリ

テーマ（試験）→ 単元 の順に選び、過去問をランダムに出題するための個人用ツールです。

公開ページ: https://gamenodes-web.github.io/kakomon/

## できること

- テーマ・単元ごとに、開始No〜終了Noの範囲から重複なしでランダム出題
- 正解回数・不正解回数をプルダウンで記録し、その回数で出題対象を絞り込む
- 問題ごとにURLと写真（複数枚）を登録。写真はスクリーンショットの貼り付け（Ctrl+V）にも対応
- 単元管理での並べ替え、複製、Ctrl+Z での取り消し
- カレンダーに日付ごとのメモ
- ZIPでの書き出し・読み込み（PCとスマホの間でのデータ移動、バックアップ用）
- ホーム画面に追加するとアプリのように起動。通信が無くても動作します

## データの扱い

**入力したデータはこのリポジトリにも、どこかのサーバーにも送られません。**
問題・写真・記録・カレンダーは、すべて使っている端末のブラウザ内
（localStorage と IndexedDB）にのみ保存されます。外部への通信は行いません。

そのため、ブラウザのデータを消すと内容も消えます。ZIPでの書き出しを
定期的に行ってバックアップしてください。
また、端末を他の人と共有している場合は、端末側のロックで保護してください。

## 構成

ビルド不要の単一HTMLです。React・JSZip・Tailwind のCSSを同梱しているため、
外部CDNへ接続しません。
